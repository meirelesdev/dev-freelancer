# Dev Freelancer

> Aplicacao para gerenciamento de projetos e clientes para freelancers, com controle de receitas, despesas e status de projetos.

## Stack

- HTML5
- CSS3
- JavaScript

## Prerequisitos

- Nenhum prerequisito especifico

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/dev-freelancer.git
cd dev-freelancer
```
